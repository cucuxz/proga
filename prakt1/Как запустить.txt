Практическая работа №1. Работа с классом Console.

Откройте prakt1 и дважды нажмите «Запустить.command».
Исходники: код/NortonCommanderConsole/Program.cs — весь код в одном файле.
Отчёт: отчет. Все данные находятся в списке метода Program.CreateFiles.
Выход из программы — любая клавиша.

Команда из папки проекта: ./run.command
На другом компьютере нужен .NET SDK 8; команда: dotnet run
Размер терминала — не менее 80 столбцов и 25 строк.
