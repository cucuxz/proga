Практическая работа №1. Работа с классом Console.

На Mac дважды нажмите «Запустить.command» в папке prakt1.
Программа запустится в том же окне Terminal, без открытия второго окна.
Альтернативный запуск: «Запустить.terminal» открывает окно 80×25.
В обоих случаях программа выводит классические цвета Norton Commander:
синий фон, голубые рамки и имена, жёлтые заголовки, бирюзовое меню.
Профиль запускает код из папки «учеба/proga 2 sem/prakt1».
Остальные окна и стандартный профиль Terminal не меняются.
Выход из программы — любая клавиша.

Исходники: код/NortonCommanderConsole/Program.cs — весь код в одном файле.
Все записи хранятся списком в Program.CreateFiles. Настоящий диск не читается.
Отчёт Word — в папке «отчет».
На другом компьютере с .NET SDK 8: dotnet run из папки проекта.
На Mac и в VS Code программа использует фиксированную палитру 256 цветов:
синий #0000AF, голубой #5FFFFF, бирюзовый #00AFAF, жёлтый #FFFF00.
Цвета этих элементов не зависят от темы терминала.
Архив «Практика_1_Исходники.zip» содержит только Program.cs, .csproj и NuGet.Config.
