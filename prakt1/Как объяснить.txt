Как объяснить практическую работу №1

1. В одном Program.cs три класса. Program запускает приложение,
   FileEntry хранит сведения об одной записи, Commander рисует интерфейс.

2. Данные — List<FileEntry> в Program.CreateFiles. Чтобы добавить файл,
   достаточно добавить строку new FileEntry("name.txt", 1234, newDate).
   Последний параметр true означает каталог. Настоящий диск не читается.

3. SortFiles сортирует копию списка по имени без учёта регистра.
   Служебный родительский каталог «..» ставится первым.

4. WriteAt вызывает Console.SetCursorPosition, задаёт ForegroundColor
   и BackgroundColor и печатает строку через Console.Write.
   Frame рисует углы, горизонтальные и вертикальные линии псевдографикой.

5. Слева три колонки по 17 строк. Для записи i колонка — i / 17,
   строка — i % 17. Math.Min ограничивает число выведенных записей.
   Справа четыре поля: имя, размер, дата, время.

6. ShortName оставляет начало длинного имени, знак ~ и расширение.
   Например MyFileWithLongName.txt становится MyFileW~.txt.

7. Файлы голубые, каталоги белые. Первая строка правой панели выделена.
   Окно занимает 80×25. Последний пустой символ не печатается,
   чтобы терминал не прокрутил изображение.

8. Кнопки только нарисованы. Любая клавиша завершает приложение.
   При изменении размера окна панели рисуются заново.

Если спросят про _lines и textOnly: это только текстовая версия для вывода
в файл и автоматических проверок. При обычном запуске WriteAt печатает
сразу в консоль. Экспорт в JSON и отдельные классы ячеек не используются.
