Лабораторная работа №2, вариант 9. Обе части в одной программе.

На Mac: дважды нажмите «Запустить.command».
Для проверки модульных тестов: «Проверить тесты.command».
Результаты MSTest сохраняются в папке «результаты тестов».

Кнопка ▶ в VS Code:
1. Откройте файл «Лабораторная_2.code-workspace» через File → Open Workspace from File.
2. Откройте Program.cs. Основной код целиком в этом файле.
3. В Run and Debug выберите «Лабораторная 2 — вариант 9» и нажмите ▶ или F5.
Настройки сборки и запуска уже находятся в .vscode. Нужно расширение C# от Microsoft.
Консоль работает во встроенном терминале VS Code и ждёт выбор пункта меню.

На компьютере с установленным .NET SDK 8:
dotnet run --project код/Lab2Variant9/Lab2Variant9.csproj
dotnet test код/Lab2Variant9.Tests/Lab2Variant9.Tests.csproj

Для демонстрации обеих частей без меню:
dotnet run --project код/Lab2Variant9/Lab2Variant9.csproj -- --demo

При первом запуске тестов на новом компьютере нужен интернет для загрузки NuGet.
Архив исходников содержит код, проекты, решение и настройки VS Code.
Файлы .command, отчёт и результаты тестирования лежат в полном комплекте.
