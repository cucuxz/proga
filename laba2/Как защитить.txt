Лабораторная №2. Короткое объяснение.

1. В Program.cs сначала Password и Extensions, потом классы людей, затем меню.
2. Password хранит строку в readonly-поле. Свойства Value и Length доступны только для чтения.
3. Индексатор password[i] читает символ с позиции i, нумерация с нуля.
4. password - '#' заменяет последний символ и возвращает новый Password.
5. > и < сравнивают длину, == и != сравнивают сами строки с учётом регистра.
6. ++ сбрасывает пароль на Default1!. p++ возвращает старый объект, ++p — новый.
7. if (password) вызывает operator true. Для него C# требует парный operator false.
8. Стойкость: 8–12 символов, верхний и нижний регистр, цифра и спецсимвол, без пробелов.
9. Методы расширения — static-методы с this у первого параметра.
   MiddleCharacter выбирает средний символ строки, при чётной длине — левый.
   HasValidLength проверяет только длину 6–12, а не стойкость.
10. Person — абстрактный базовый класс. Его данные создаются внутри PersonData: композиция.
11. Две ветви: работающие и обучающиеся. Turner и PartTimeStudent отмечены sealed.
12. Person[] хранит объекты семи разных конкретных классов.
    Вызов GetRole, DescribeActivity и ToString через Person выбирает реализацию потомка.
13. Equals сравнивает людей по постоянному Id. GetHashCode основан на том же Id.
    ToString показывает фактический тип и все общие и специальные значения.
14. Finalize задан учебным деструктором ~Person(). Его время вызова выбирает GC.
    GetType и MemberwiseClone не virtual, поэтому их переопределить нельзя.
15. Модульные тесты находятся в Tests.cs. [TestClass] обозначает класс тестов,
    [TestMethod] — отдельную проверку. Assert сравнивает фактический и ожидаемый результат.
    Настоящий запуск dotnet test выполняет 32 теста и создаёт tests.html и tests.trx.
