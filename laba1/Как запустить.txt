Лабораторная работа №1. Вариант 8 — компьютерная техника.

Запуск на этом Mac: дважды нажмите «Запустить.command» в папке laba1.
В программе: 1 — добавить, 2 — показать, 3 — удалить, 0 — выйти.
Сведения заполняются во время запуска; сначала список пуст.

Код: код/ComputerEquipmentLab.
Отчёт Word: отчет/Лабораторная_1_CSharp_Естифеев_АВТ-513.docx.
Краткие ответы для защиты: Для защиты.txt.

На другом компьютере нужен .NET SDK 8. Из папки «код»:
dotnet run --project ComputerEquipmentLab/ComputerEquipmentLab.csproj

Тесты из папки «код»:
dotnet run --project ComputerEquipmentLab.Tests/ComputerEquipmentLab.Tests.csproj
Фактический результат проверки: 18/18 тестов пройдено.

Для преподавателя подготовлен отдельный архив Лабораторная_1_Исходники.zip.
Он содержит приложение и модульные тесты, без launcher, отчёта, bin и obj.
