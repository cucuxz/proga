Лабораторная работа №1. Вариант 8 — компьютерная техника.

На этом Mac дважды нажмите «Запустить.command» в папке laba1.
Меню: 1 — добавить, 2 — показать, 3 — удалить, 0 — выйти.
Сначала список пуст. Данные сохраняются на время одного запуска.

Весь исходный код: код/ComputerEquipmentLab/Program.cs.
В этом файле находятся три класса устройств и Program с меню.
ComputerEquipmentLab.csproj содержит настройки сборки проекта.
Отчёт: отчет/Лабораторная_1_CSharp_Естифеев_АВТ-513.docx.
Краткие пояснения: Для защиты.txt.

На другом компьютере установите .NET SDK 8. Из папки проекта:
dotnet run --project ComputerEquipmentLab.csproj

Для преподавателя: Лабораторная_1_Исходники.zip.
В архиве только Program.cs и ComputerEquipmentLab.csproj.
