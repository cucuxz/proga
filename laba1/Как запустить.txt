Лабораторная работа №1. Вариант 8 — компьютерная техника.

Запуск программы
Дважды нажмите «Запустить.command» в папке laba1.
Меню: 1 — добавить, 2 — показать, 3 — удалить, 0 — выйти.
Сначала список пуст; данные сохраняются на время одного запуска.
Весь код приложения находится в код/ComputerEquipmentLab/Program.cs.

Модульные тесты MSTest
Дважды нажмите «Проверить тесты.command» в папке laba1.
Запуск выполняется стандартной командой dotnet test.
Ожидаемый итог: всего 18, пройдено 18, ошибок 0, пропущено 0.
Весь код тестов находится в код/ComputerEquipmentLab.Tests/Program.cs.
Тестовый проект подключает приложение и официальные пакеты Microsoft.
При первом запуске на другом компьютере нужен интернет для NuGet.
После выполнения откройте результаты тестов/tests.html в браузере.
Раскройте All Results: будут видны названия и результаты всех тестов.
Также сохраняется протокол tests.trx.

Запуск на другом компьютере с .NET SDK 8 из папки «код»
Программа:
dotnet run --project ComputerEquipmentLab/ComputerEquipmentLab.csproj
Тесты:
dotnet test ComputerEquipmentLab.sln -c Release --logger "console;verbosity=normal"
Для получения HTML- и TRX-отчётов добавьте параметры, приведённые в разделе 2.5.2 отчёта Word.
В Visual Studio откройте ComputerEquipmentLab.sln и выполните тесты через Test Explorer.

Отчёт Word находится в папке «отчет».
«Лабораторная_1_Исходники.zip» содержит приложение, MSTest, настройки и файл решения.
Файлы запуска, результаты сборки и пакеты NuGet в архив исходников не включены.
