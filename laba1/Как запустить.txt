Лабораторная работа №1. Вариант 8 — компьютерная техника.

Запуск программы: дважды нажмите «Запустить.command» в папке laba1.
Меню: 1 — добавить, 2 — показать, 3 — удалить, 0 — выйти.
Сначала список пуст; данные сохраняются на время одного запуска.
Весь код приложения: код/ComputerEquipmentLab/Program.cs.

Запуск тестов: дважды нажмите «Проверить тесты.command».
Ожидаемый итог: «Итого: 18/18 тестов пройдено».
Весь код тестов: код/ComputerEquipmentLab.Tests/Program.cs.
Тестовый проект ссылается на приложение и не требует внешних пакетов.

На другом компьютере нужен .NET SDK 8. Из папки «код»:
dotnet run --project ComputerEquipmentLab/ComputerEquipmentLab.csproj
dotnet run --project ComputerEquipmentLab.Tests/ComputerEquipmentLab.Tests.csproj

Отчёт Word находится в папке «отчет».
Для преподавателя подготовлен «Лабораторная_1_Исходники.zip»:
приложение, тесты и настройки обоих проектов; без файлов запуска и сборки.
