Лабораторная №1 — короткие пояснения к Program.cs

Что делает программа?
Хранит устройства в списке: можно добавить, показать и удалить по номеру.
Весь код находится в одном Program.cs. Отдельно подключать классы не нужно.

Какие классы здесь есть?
ComputerEquipment — общие свойства: производитель, модель, цена, год.
PersonalComputer — добавляет процессор, память и наличие видеокарты.
Laptop — добавляет процессор, память, экран и аккумулятор.
Program — меню, список и ввод данных.

Как работают поля и свойства?
Поля private закрыты от прямого изменения. Свойство public читает поле через get,
а через set проверяет новое значение и сохраняет его. value — новое значение.
Свойства проверяют данные даже при создании объекта без меню.

Для чего this и base в конструкторах?
this(...) вызывает другой конструктор того же класса.
base(...) вызывает конструктор родителя и заполняет общие свойства.
Конструктор без параметров задаёт готовые значения; второй принимает параметры.

Что такое virtual, override и полиморфизм?
virtual разрешает переопределить GetInfo. override задаёт вывод потомка.
В List<ComputerEquipment> хранятся и базовые устройства, и ПК, и ноутбуки.
При просмотре выбирается GetInfo фактического типа объекта.
ToString тоже вызывает GetInfo и возвращает описание устройства.

Как устроено меню?
while повторяет меню, switch выбирает действие. 0 завершает цикл.
CreateDevice создаёт устройство, ShowDevices показывает список,
DeleteDevice вызывает RemoveAt(number - 1): номера с 1, индексы с 0.

Как проверяется ввод?
ReadText не принимает пустую строку. ReadInt и ReadDecimal используют TryParse:
если ввод неверный, запрос повторяется. Дробь можно вводить с точкой или запятой.
Цена может быть нулевой, память, экран и аккумулятор должны быть положительными.

Что такое const, readonly, decimal и protected?
const задаёт постоянное значение, например минимальный год 1900.
readonly у devices запрещает заменить сам список, но разрешает добавлять записи.
decimal используется для цены и диагонали. protected открывает методы потомкам.
Стрелка => — короткая запись get или метода с одним возвращаемым выражением.

Как показать программу?
Показать пустой список. Добавить ПК и ноутбук. Вывести оба устройства.
Удалить ПК по номеру. Показать оставшийся ноутбук с номером 1.
Попробовать отрицательную цену: программа должна повторить запрос.
После выхода список исчезает: хранение в файле в этой работе не реализовано.

Как устроены модульные тесты?
В отдельном проекте есть класс ComputerEquipmentTests с атрибутом [TestClass].
Каждый метод с [TestMethod] — самостоятельный тест, его запускает MSTest.
Assert.AreEqual сравнивает ожидаемое и фактическое значения.
StringAssert.Contains проверяет текст, Assert.ThrowsExactly — тип исключения.
Например, тест NegativePriceRejected задаёт цену -0.01 и ждёт исключение,
после чего убеждается, что прежняя цена сохранилась.
Откройте Проверить тесты.command: dotnet test выполнит 18 тестов.
В tests.html видны количество, названия и результаты тестов.
Приложение по-прежнему находится в одном Program.cs.
