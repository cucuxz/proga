Лабораторная работа №1 — короткая памятка

Сначала скажи:
«Я сделал учёт компьютерной техники. Есть базовый класс и два потомка:
персональный компьютер и ноутбук. Они хранятся в одном списке.
Меню позволяет добавить объект, показать свойства и удалить запись».

Порядок показа кода:
1. ComputerEquipment.cs: четыре общих свойства, проверки и два конструктора.
2. PersonalComputer.cs и Laptop.cs: наследование, base и свои свойства.
3. GetInfo: virtual в родителе, override в потомках.
4. Program.cs: List, меню, добавление, вывод и RemoveAt.

Что такое класс и объект?
Класс описывает данные и поведение. Объект — конкретный экземпляр,
например ноутбук Asus Zenbook с заданной ценой и характеристиками.

Где наследование?
В записи «class Laptop : ComputerEquipment». Ноутбук получает общие
свойства техники и добавляет свои: экран, аккумулятор, процессор и память.

Что делает base(...) в конструкторе?
Вызывает конструктор родителя с производителем, моделью, ценой и годом.
В теле конструктора потомка заполняются дополнительные свойства.

Зачем два конструктора?
Без параметров создаёт допустимый объект по умолчанию.
С параметрами создаёт объект с введёнными характеристиками.
this(...) вызывает другой конструктор этого же класса.

Что означают private, public, protected?
private — только внутри класса; public — доступ снаружи;
protected — доступ внутри класса и его потомков.

Чем поле отличается от свойства?
Поле хранит значение. Свойство управляет чтением и записью через get и set.
В set проверяем значение до присваивания: отрицательная цена запрещена.
Стрелка «get => _price» — короткая запись возврата значения поля.

Где полиморфизм?
В ShowDevices вызывается devices[i].GetInfo(). Тип списка —
ComputerEquipment, но для ПК вызывается его override, а для ноутбука — его.
virtual разрешает переопределение; override задаёт новую реализацию.

Зачем ToString?
Это стандартное строковое представление объекта. В моём классе
оно вызывает GetInfo, поэтому тоже учитывает фактический тип.

Почему List<ComputerEquipment>?
В него можно добавить базовый объект, ПК и ноутбук. List хранит порядок
добавления, автоматически увеличивает размер и позволяет удалять по индексу.

Почему RemoveAt(number - 1)?
На экране номера идут с 1, а индексы List — с 0.
Удаляем нужный элемент, порядок остальных сохраняется.

Как проверяется ввод?
TryParse возвращает false при вводе текста вместо числа. Тогда повторяем
запрос. Сначала проверяется диапазон, затем возвращается подходящее значение.
Trim убирает пробелы по краям. Запятая заменяется точкой при вводе дроби.

Зачем проверки ещё и в свойствах?
Объект можно создать или изменить из другого кода, минуя меню.
Свойства защищают правильность данных в каждом таком случае.

Что такое decimal и const?
decimal подходит для десятичных денежных значений.
const — неизменяемое значение, например нижняя граница года выпуска.

Что делает catch (EndOfStreamException)?
При закрытии потока ввода ReadLine возвращает null. Вспомогательный метод
сообщает об этом исключением, а Main завершает работу с обычным сообщением.

Как проверить работу на защите?
Показать пустой список; добавить ПК и ноутбук; вывести оба объекта;
удалить ПК по номеру; снова показать список. Попробовать отрицательную цену.
Затем запустить тесты: 18/18. Они проверяют конструкторы, свойства,
недопустимые значения, полиморфизм и сохранение порядка после удаления.

Где данные после выхода?
В этой работе они живут в памяти только во время запуска программы.
