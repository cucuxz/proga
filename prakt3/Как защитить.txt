Практика 3, вариант 1 — коротко для защиты

1. ArrayList хранит object: вместе находятся пять int и строка C#.
2. Remove удаляет первое совпадение; Count показывает количество; Contains ищет значение.
3. Stack<char> хранит только символы, Stack<ComputerEquipment> — только объекты техники.
4. Стек работает по LIFO: последний вошёл — первый вышел.
5. Push добавляет на вершину; Pop удаляет и возвращает вершину. Других методов добавления у Stack нет.
6. RemoveTop сначала проверяет n, потом вызывает Pop n раз; неверное n не меняет стек.
7. new List<T>(stack) создаёт список в порядке обхода стека: от вершины к основанию.
8. Все коллекции выводятся через foreach в методе Print.
9. ComputerEquipment взят из первой лабораторной: производитель, модель, цена, год.
10. IComparable.CompareTo сравнивает цены. List.Sort() вызывает этот порядок.
11. EquipmentComparer реализует IComparer: сортировка по производителю, затем модели.
12. ICloneable.Clone создаёт новый объект и новый список Accessories. Изменение копии не меняет оригинал.
13. Строки неизменяемы, поэтому элементы списка строк можно перенести в новый список.
14. Обычное присваивание объекта копирует ссылку. Конструктор List<T>(stack) тоже переносит ссылки на технику; Clone отдельно копирует саму технику.
15. Поиск техники идёт по Model без учёта регистра; это поиск значения свойства, а не ссылки.
16. ObservableCollection сообщает об изменениях через событие CollectionChanged.
17. += подписывает OnCollectionChanged; Add и Remove вызывают его автоматически; -= отписывает.
18. В PDF указано CollectionChange, но настоящее имя события в .NET — CollectionChanged.
19. --demo использует Random(1), чтобы числа в отчёте воспроизводились; обычный запуск — new Random().
20. Тесты запускаются MSTest: Assert сравнивает фактические значения с ожидаемыми, а не просто печатает «успех».
